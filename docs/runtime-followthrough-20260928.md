## 修复内容

### 1. 身体转向完成后，不再错误回报失败

原 c37 的身体实际已转约 -90.096°，但动作监视器在后续结算前清空了测量结果，完整原句又留在剩余目标中，导致多走一次规划并报失败。

现在角色采纳原子身体转向时先登记角度要求；真实 native terminal 测量保留在同一个 SceneAction 中。结算核对 action、capture、实测角度、朝向误差、根节点位移及任务所有权。实际完成的单步目标可消耗原句残留；独立复合尾项仍保留，迟到或重复回调不能再追加失败回执。

实际 Qwen 回放还发现了数值编码问题：左转90被写成代表右转的 `yaw=+90`。已为登记过的原子 body_turn 改为 `direction=left|right` 加固定 `degrees`，由程序换算有符号 yaw。这不增加模型轮次，也不按用户关键词强制执行。旧无合同身体/普通头部视线路径保持兼容。

### 2. 连唱使用稳定素材身份，当前条件进入核查

每条录音的完整转写与稳定 clip 直接绑定。perform 必须有与选材一一同序的内容引用，不能把另一条录音的歌词移植到当前引用上。已采纳录唱的选择不能被素材规划器私自改成“不唱”或自由编写“少了一段”的事实；不确定时使用绑定当前问题的结构化澄清。

`current_fact` 表示现在可核查的录音/范围条件，完整用户原话、角色选择、条件和目标都传给录唱规划器，并不假设条件已满足。真正等待未来事件的条件仍单独处理，不能删除条件后立即执行。

普通回唱、现有范围选择与多段连接仍走专用录唱表格，不增加审核轮次。裁切、变调、曲库查询等表外提案才触发一次独立能力边界核验。需要 General 时只私下生成候选，校验具体操作、稳定音源顺序、当前输入、来源证据后，再进入既有独立目标审核。私下候选的文字不会送到公开语音回调，也不会记成已交付台词。裁切/变调交接保留原始角色意图，避免 Fast owner 结束后独立审核丢掉完整目标。

保留角色自主拒绝；不是把用户所有指令都强制执行。完整工具链的旧标签词汇仍用于现有能力，未从全工程删除。

### 3. 历史灯不在画面内、当前灯超距时保留目标并补前置步骤

已知实体不在当前画面时，Room 可以明确选择 `reobserve-object`：只用历史观察点进行有界转向，再拍新图确认同一实体。历史身份不赋予当前可见性、位置、可达性或开关权限。

当前可见设备超出操作距离时，Room 必须明确选择接近，并保留原来开灯目标；到达后继续原同实体、可见性、几何、导航、距离和设备结果检查。没有在设备执行器中偷偷增加自动导航，也没有放宽原门限。

原始意图由程序绑定的 source_ref 引用，避免模型改写 evidence 后被错误拒绝。异步步骤绑定 plan、revision、turn、工作 epoch 和用户轮次；取消、换目标、关闭对象感知后，旧步骤失效。旧动作清理只能影响自己的 action/operation。

### 4. 减少没有新语音时重复重启推理

原 c6/c7/c8 没有确认新的人声，RMS 兜底仍重开录音，并把旧 PCM 合并后重新派发同一句输入。

新增窄范围门禁：同一已完成输入尚未开始输出、同麦克风、旧录音关闭后三秒内、完整且新鲜的神经 VAD 窗口明确否定 speech/tonal 时，暂缓该 RMS 重开。保留原始候选起点、预卷与流游标；后续真说话、短补充、歌词尾音、重复说话及打断仍走原流程。不可用、畸形、过期或阳性 VAD 不能否定人声。

没有增加全局文本去重，也没有按文字删掉混合回声。新增 trace 能在下轮日志中确认门禁是否实际命中。
