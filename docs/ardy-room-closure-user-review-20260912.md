## 下一阶段优先级

1. 先补停止短指令的可靠传递。保存同一录音内的有效流式观测及其录音身份，查明最终空结果为何覆盖它；防止误用上一轮、否定句或引用内容。增加从收音、最终识别、意图提交到实际停止的关联记录。停止意图确认后直接中断当前任务，保持语音回复独立；不把任意开口或未经确认的 partial 当作停止。
2. 紧接着做同层长路线分段，把可达但超过单次预算的路线拆成持续任务，提前准备下一段，统一停止与过期结果处理。停止覆盖当前播放、正在生成和排队段，才适合作为连续跟随的基础。
3. 再接动态目标更新与跟随。台阶、视觉和更多地形另行验收；本次不建议为了延长测试时间直接放宽单段上限或放松地形检查。

正常呼唤可以通过本轮体验验收；“语音行走中停止”仍是明确未通过项。无需因此继续围绕短距离动作反复训练，优先完成控制可靠性和长任务执行框架。
