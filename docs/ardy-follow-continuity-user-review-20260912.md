两种停止入口最终都走同一取消链：`StopForTask → StopMovement → controller.Cancel → CancelCore → player.Stop`。读取时控制器 `CancelCore` 直接调用 `player.Stop()`；播放器 `Stop` 会恢复保存的骨骼局部姿态并释放身体控制。自然到达则走 `ReturnToAnimation`，逐帧混合回当前 Animator。最新会话中 9 次未被打断的自然衔接耗时为 **0.404–0.409 秒**。

沿主移动方向，实际距离可分解为 **0.286005 米未刷新用户位移 + 1.2 米选中站距 − 0.005080 米根节点前移误差 = 1.480925 米**。计入 X 方向后，实际根节点与合法站位的平面误差也仅约 **5.4 毫米**。因此主要原因是目标刷新门槛留下的残差和已选定的外环站距叠加，而非原生动作提前停在距离目标 0.2 米的位置。

当前规划器以 `route.Length + abs(turn) * .015 + ring * .15` 比较候选；近侧外环站位可省约 0.2 米路线，环惩罚只有 0.15，因此在无遮挡平地也可能选择 1.2 米环。本轮保留该合法站位选择，修复方向是在用户水平位置稳定至少 0.30 秒后，将超过 0.06 米的最后残差再做一次受原有路径与净空约束的滚动更新。移动中的 0.35 米门槛及更新限频继续保留；不足以安全续播时仍停稳后规划。测试距离断言保持不变，等待新运行验证。
