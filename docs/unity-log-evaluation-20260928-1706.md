## “根治”可以承诺的范围

可以把工程保证做成：执行器只转换指定原PCM中的一个已批准、版本明确的歌唱子区间；同一确认范围不因续录静默改变；修改范围必须生成新版本；重复回调不能重播；已开始、未开始、已完成的状态来自实际回执。这能消除本次可复现的失配链。

不能诚实承诺任意自然混合录音、唱念、哼唱、噪声和重叠声音都能100%自动切分正确。若允许用户显式标记歌唱区间，可以严格保证不播放区间外的音频；区间内部本身是否含口语仍是另一件事。自动模式需要为不确定边界保留进一步分析、询问或不播放的选择，而不是把unknown改名clean后直接通过。

建议下一批顺序：

1. 建立lastPlayback绑定的“剪掉开头口语→边界细化/对齐→原PCM坐标→新范围版本→回唱”执行链；用本场c23/c24同源片段做回归，不能凭文字长度猜秒数。
2. 混合片段进行边界细化，明确细化成功/仍不确定；逐步将结果在采集/ASR过程中异步准备，不给普通对话额外添加一轮LLM。
3. 保留修剪任务与已知源，禁止同证据重新检索代替范围修改；明确承诺发表前要与实际已采纳任务对应。用c28/c30/c34原始样本检验。
4. 接通真实动作完成引用，让“非常好”能得到自然回应；同时保留防止虚报完成的检查。
