# 从看见物件到自主走近

本批把「像素命中了哪块几何」与「这是不是本轮想看的物件」分开。Unity 提供本帧可见轮廓、部件所属实体、局部层级与已登记能力；共享的 Qwen 根据这些客观资料和实际图像核对意图。模型的语义判断仍可能出错，不能称为引擎证明。

## 选择与核对

- 同一张角色视野图提供最多 6 个实际可见候选，保留原图像素坐标、captureId 和时间；附同图局部放大，不制造新的视觉细节。
- 候选轮廓来自可见不透明 ID 像素。透明遮挡后的物件、视野外物件不会通过层级查询泄漏到候选中。
- 局部资料包含选中部件、实体根及最多 6 层从属关系。已登记灯具可附其明确登记的发光部件和 Light 节点；这些名称属于引擎资料，不表示每个部件都可见。
- Qwen 只返回本次 c1…c6 中的选择或不确定。选错普通柜面、给出不存在的旧编号，可以在当前候选中改选；设备能力和后续新图确认仍独立校验。
- 用户纠正立即撤销旧描述与实体的关联，保留真实观察历史。不确定的注视仍可转向图像区域获取新视野，不据此开关或移动。

## 走近以便看清

`approach-object` 可以接近已确认的目标，也可用 `targetPurpose=observe-closer` 选择较大的可见参照，例如小灯旁的电视柜。后者只确认观察参照，不声称已经识别小灯。

观察子目标保存独立的 `goalId` 和原始目的。后续决策显式带 `observationGoalId` 才续接；省略时不会自动套用旧目的。新用户轮次使旧目的转为历史，自主行动不能自行恢复被新指令取代的旧目的。原目标续接经过语义核对及真实新图确认后，观察子目标关闭。

取消当前执行会使旧异步回包失效，不会永久删除独立的观察记录；同轮次后续仍须用全新的决策显式续接并重新核对。停止再启动同一房间会话也不等于自动放弃所有观察愿望。

行走沿现有房间导航和 ARDY 执行。目标锚点可以在原截图过期后继续用于已提交的行走，但不能用旧图发起新动作。房间、角色、目标身份、几何与移动范围仍校验。地面到达与目标重认是两件事：`groundArrived` 表示实际到达合法站位；`objectReobserved` 表示之后在真实新图中重新看到了同一实体。

原始关注点单独保留。大柜体的代表像素可能落在顶部，不能直接拿它替换角色想看的区域。观察站位使用同一物件、同一已见区域附近的实际不透明表面，结合眼高、颈部角度和到达误差选距离；不捏造目标高度，也不扩大颈部活动限度。

行走中的关注与导航分别维护：短期记住的目标区域供已提交的路线使用，低频本地新图确认当前是否还能看见它。注视点随实际身体位置逐帧调整头眼，无需逐帧请求 Qwen。暂时遮挡会撤回注视而保留有效导航；重新看见后才恢复关注。目标移动、环境或行动归属改变继续由导航守卫处理。

头部关注由当前 ARDY 播放器在当帧基础姿态上应用，避免两个系统争写骨骼。局部头眼关注限制旋转幅度与速度；这约束的是附加关注层，不代表任意 ARDY 基础姿态都已通过完整的人体关节限制。停止沿用实际最后一帧姿态平滑交还待机。关注退出时同一动作可以凭新观察重新取得关注；不同动作要等旧关注层完成回位，不能直接抢写骨骼。

## 运行与验证

现有 `Tools/NeEEvA/Character Scene Vision` 窗口新增目标核对结果、历史候选图和「到达 / 同物重认」。候选图注明历史快照，和不断刷新的当前视野分开显示。

全部测试使用现有隔离项目 `Server/ARDY/runtime/unity-naturalness-validation`。主聊天场景未改写或保存。证据放在 `Server/ARDY/runtime/scene-object-approach-20260913/`；最终通过情况以该目录的交付核验报告为准。

`live-matching-r1` 已完成真实共享 Qwen 的一次当前图核对：初始像素故意落在灯旁背景，模型从候选中选择了实际小灯 c2，返回约 1.49 秒。生产流程随后实际转头并用另一张新图确认同一实体。同期通过候选图 41 项、匹配及观察目标生命周期 105 项、传输 38 项及原开关灯/引用/反馈回归。此为一个真实语义样本，其余边界使用受控回包，不能推算日常成功率。

最终 `final-integration-r4` 完整通过，Unity 正常退出且无 C# 编译错误。真实 ARDY 走近时有 7 次移动中的新图确认，并记录到实际头部关注姿态；正常到达后重新看见同一实体。另一次在到达时遮挡目标，系统正确反馈 `groundArrived=true`、`objectReobserved=false`，没有把到达冒充看见。独立关注回归验证了真实 Humanoid 头部转动、同动作重新取得注视、超时回位、停止时保留最后姿态及旧控制者不能继续写骨骼；本次导入模型走的是直接 Humanoid 绑定。

`attention-r1` 的 47 项既有站立头眼、待机共存及 ARDY 点头控制检查通过。`final-verification.json` 核对了 1,200 个源文件与隔离项目完全一致，主聊天场景哈希与本批开始时一致。真实 Qwen 语义样本与真实 ARDY 导航分别验证；本批没有进行完整语音对话的日常成功率测试。

测试时重新进入 Play，让 Unity 加载最新代码。可观察「去近一点看看电视柜上的小灯」，再检查或开关同一盏灯；也可让角色自由观察房间。窗口里重点区分目标核对、行走中实际视野确认、地面到达、到达后重新看见。候选图是提交核对时的历史资料，不是持续可见证明。

本批不包含物理伸手触碰、抓取、上下台阶、任意 Inspector 写入，也不证明任意自然语言目标的识别成功率。程序灯具开关继续使用已登记的独立能力。
