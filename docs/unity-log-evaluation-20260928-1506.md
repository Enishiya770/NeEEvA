## behavior.txt 与 singing.txt：用途和删减判断

项目实际文件名为 `Assets/AIChatTookit/Prompts/behavior.txt`（用户称 behaviour.txt）和 `Assets/AIChatTookit/Prompts/Skills/singing.txt`。

**本次关键路径没有直接使用这两份旧标签手册。** 新场 10 条 FormalPromptProfile 全为 `recording-singing-ir-v1`，没有 General/compact-legacy-tools；录唱请求的角色选择、素材和证据有独立 JSON 合同。FastLoop/ActorIntent 同样用各自合同。应区分源文件中仍存在的 XML 说明、模型真正收到的协议、程序编译后的 XML 执行桥。

日志 `wireSystemTokensEstimate=81` 只是投影后基底 system 的估算，真实发送时还拼入专用 IR 合同，不能声称完整系统提示只有 81 token。singing Skill 投影为短路由说明，也不能等同于所有歌唱事实都只有几十 token。
