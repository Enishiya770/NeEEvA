## 已实现

### 行为原则和传输协议分开

`behavior.txt` 从约 14946 字符缩到 1307 字符，`Skills/singing.txt` 从约 8344 字符缩到 1170 字符。这两份文件保留角色自主选择、事实和记忆依据、完整理解当前用户、录音身份/范围/真实交付等原则，移走详细标签示例。

仍被 General 兼容路径使用的接口分别保存在 `Resources/PromptProtocols/general_tools.txt` 与 `singing_tools.txt`。程序按路径显式加载；结构化路径继续由各自 schema 定义输出。修改角色资产、缺少原资产布局、冻结 system 与新资产不相等，或者旧输出合同后缀变化，不再触发隐式回退。

FastLoop 实际读取精简后的行为原则。它比原先忽略 behavior 的 FastLoop 多一段稳定前缀，不能把文件缩减比例直接当作首音提速比例。General/曲库兼容能力仍需要标签；本批没有声称全部链路已经去标签化。必需协议资源丢失会明确中止请求构建，不静默降低能力。

### 档案定位和展开收敛

小档案能够容纳时一次展示全部录音和接受输入的紧凑目录，保留所有条目。目录给出真实已完成播放身份及关联输入，模型仍负责理解并选择。选择后的候选材料和关联原话批量完整展开，随后才进入 IR 和独立审核。

移除了“先搜索”的固定引导，明确搜索是单个连续字面片段。已访问页、已展开材料及输入事件按同一 snapshot 累积，重复页、相同/子集候选和 A→B→A 不再无限重走。真正新增证据仍可继续。大档案保留分页和总检索预算，原始转写和 PCM 不裁剪。

`source_expansion` 可携带已知稳定 key 的短提示 quote，避免仅因非空 quote 格式而拒绝找源；quote 不作为来源证明，正式 perform 仍须完整证据核验。每次检索有独立 trace，后续可准确统计每个 HTTP 等待。

### 本地失败说明进入语音通道

档案未收敛和资料超预算等提前返回分支，原先只完成字符串，未触发语音回调。现在先解析程序生成的公开语句，经 typed speech 或 legacy delta 通道投递，再通知完成；不会双播。请求 generation 变化后立即停止剩余投递和历史提交。自动纠错耗尽等其他系统诊断仍保留既有系统通知边界。

纯中文的绑定引文与日语澄清模板分开声明语言，公开文字保持原样。中日同形专名仍保留原语言判断；同时含假名和中文的复杂混合引文不在本批完整覆盖范围。

### 身体任务有显式交接

RoomTask 可对当前精确 follow 身份提交 `bodyHandoff`。已选择与跟随互斥的有限动作时必须显式选择交接，决定保留跟随则不提交该动作。有限任务结束不自动复活旧跟随；若已采纳目标还包含继续跟随，则必须保留为计划的后续步骤，通过现有 RoomTask 链实际提交新的 follow。

程序通过原有平滑停止流程释放身体，最多等待三秒；不会绕过控制器、姿态、导航和质量检查。新输入、停止、场景/控制器/用户绑定变化或计划取消会撤销旧交接回调。新的跟随重新读取用户位置、支撑和路径，从当前位置规划，不重放旧路线。

动作尚未提交就被拒绝时，现在生成绑定当前计划的 `attemptId` 和 `not-submitted` 结果，带真实原因进入普通对话及计划收尾。不会伪造已执行的 actionId。

### 复制旧录音不再冒充新输入

只有满足全部条件的正式音频最终回调才会保留证据而不重启回答：明确复制了上一份已接受 PCM、最终原始转写逐字相同、实际回调文本与该结果匹配、仍是同一有效麦克风和 capture 链、没有确认到新增语音或持续旋律。直接文字输入不经过这条抑制路径。

旧 PCM 区间的 VAD 不可确认新声音。新词、新录音身份、实际确认到的人声/旋律，即使重复同一句话，仍作为新输入处理。完整录音继续保留为证据；这不是 ASR 准确率或声学抗噪能力已全面改善的证明。

## 验证与边界

最终检查结果以 `work/runtime-convergence-20260928-1533/validation-summary.json` 和各子目录原始结果为准。隔离 Unity 使用重新编译的生产源码，未在主场景提交动作、转换歌声或播放音频。真实 Qwen 回放使用生产 request builder 的输出，期望答案留在 wire 外。

档案回放由最新场次的真实转写、用户原话、录音身份和已完成播放构成；日志中缺少的完整测量描述使用明确标记的受控字段，因此是重建场景，不是原始 wire 的逐字重播。模型选材、IR 编译、独立审核与最终播放是不同验证层级，结果中逐项区分。

首轮模型探针曾发现动作提案漏填交接字段，促成本批收紧契约。后续重复探针还发现 Qwen 对“不要自动继续跟随”有一次错误选择恢复模式，因此本批进一步取消了凭该字段自动恢复的机制，后续跟随必须成为实际采纳和提交的计划步骤；120 条档案夹具首版也发现普通干扰条目误继承播放元数据，已保存原始结果并修复夹具后重测。失败轮次保留，不能只保留最终成功样本。

本批未修改 ARDY 的身高门限。本场三份候选首帧高度为 0.677729 / 0.678478 / 0.679026 米，低于 0.687177 米下限。服务已先切掉旧历史帧，失败确实位于新生成段；现有证据不能证明阈值错误或某种简单平移修补安全。因此长时间跟随仍可能遇到这类质量拒绝，需要另行处理动作生成与衔接。
