# 声音教学交互重构 · 2026-09-30

用户确认的方向：平时先自动判断，不自动弹出；进入“教她”或指出声音类别错误时打开波形。口头纠正先形成候选，用户最后确认一次。目标是角色先作答、用户纠正、下次再试，而不是用户从零标数据。

## 本版交互

1. 声音学习页点击“开始教她”。已有用户档案会记住；第一次有多个档案时选择一次。自动建立采集会话，无需先填写服务地址、分组、样本坐标或容差。
2. 通过原有实时对话／按住说话录音。完整原音上传后，独立服务异步提取声学特征并提出区间。平时不弹窗、不自动播放。
3. 面板显示原始 PCM 波形、彩色类别、原音时间轴和当前选区。点击已有区间选中，拖动框选，拖动选区两端改边界；支持放大选区、显示全段、整段或选区试听、播放位置、撤销。
4. 直接点击讲话／歌唱／环境音／暂不确定纠正选区。相交区间自动拆分；同类相邻区间合并。缩短一个区间后露出的部分保持不确定，避免悄悄变成另一类。
5. 明确的口头纠正可以打开、调整同一份原录音的草稿。例如“刚才开头那句是在说话，后面才是唱歌”“刚才 3.7 到 14 秒是在唱歌”。前后顺序使用已有声学分界，缺少对应分界则留给用户拖动，不能从文字编造时间。
6. 点击“这是我的声音，判断对了／确认这次纠正”才保存并排队学习。外放、混合声源在更多设置中另行确认。只存模型预测不会自动生成训练标签。

服务地址、用户管理、练习名称、声源、任务重试和学习进度折叠在“更多设置”中。当前学习页桌面与 VR 共用同一套 Canvas 交互；VR 实机控制器手感尚需用户试用。

## 自动判断与个人学习

- 初次使用已有 PANNs 声学特征与先前开发数据的小分类头，给出完整时间线的初步猜测。它不是经过跨用户验证的通用精确分段器。
- 歌唱按分类头分数判断；说话还参考声学 speech family；低能量片段归为安静或环境音；证据不足保留不确定。
- 个人已确认的歌唱和非歌唱各达到 0.32 秒，可后台试学，不再要求先凑够三个独立分组。
- 数据较少时，下一次教学判断采用 75% 初始分数 + 25% 个人分数。这是限制稀疏反馈造成剧烈退化的工程策略，不是经过验证的最优比例。
- 三组等条件继续用于开发验证，不能把单次教学本身的改善当作泛化准确率。
- 候选、人工确认与正式执行分离。当前自动判断和试学已用于教学面板；尚未接管正式歌唱裁切／播放。

## 录音身份及并发

口头纠正开始录音时冻结先前素材，当前纠正话语即使率先上传也不会成为纠正对象。重复纠正沿用正在检查的原件；手动选择会固定检查对象。待上传、波形加载、候选请求和正式对话分离。晚到的候选不能覆盖已经改过的草稿；保存回执只清除提交时的那一版，保留保存期间继续作出的修改。原音 SHA、采样率、样本数和人工修订号均绑定。

语义入口目前是常见明确中文句式的即时解析，没有新增 Jev 或通用语义模型请求；自由表达与模糊指代的覆盖仍有限。它不会阻塞普通角色回应，实际教学结果以临时观测提供给角色，避免未确认就声称已经学会。
