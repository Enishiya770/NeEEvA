## 实施范围

1. Listening只取明确的人设来源、自然语言表达规则和本阶段JSON契约，近期对话以引用数据提供；当前原话及引用保持完整。禁止旧system整条复制进来。
2. Recording有有效snapshot时直接走专用IR，解除旧提示词资产数量、文本hash、stored system相等与尾部字符串依赖。General/Committed兼容工具路径仍保留，因此没有整份删除behavior/language资产。
3. 大录音档案共享重复说明和默认值，用有列名的表保存固定形状的测量；完整转写仍直接放在稳定key旁。显式null、缺字段、版本差异、播放回执、来源区间都有还原检查。没有丢弃最旧歌声，也没有仅按声学分数裁候选。
4. 录音器保存实际PCM继承坐标。不同clip选择了相同原PCM时，编译与最终拼接均拒绝；不自动删段、换段或按文字相似度去重。独立录制的同歌词、同一稳定音源的明确重复、互不重叠范围仍可用。
5. 选材器与独立审核接收同一份物理续接覆盖关系；说明播放列表每项只执行一次，repeat并不是次数开关。物理覆盖不替代语义判断，也不强制选择最新版本。
6. 像素命中的当前已知设备纳入显式前置规划；已绑定计划的实体编号固定为schema enum。距离、可见性、能力、所有权与同实体校验均保留。
